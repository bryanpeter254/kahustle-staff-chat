
STAFF CHAT SYSTEM (CodeIgniter)

Description:
This is an internal staff-to-staff messaging system built with
CodeIgniter, PHP, MySQL, AJAX, and jQuery.

Features:
- Staff login system
- One-on-one private chat
- Online/offline status
- Message history
- User blocking
- Profile management

Requirements:
- PHP 7.4+
- MySQL
- Apache (XAMPP / cPanel)
- Browser

Installation:
1. Extract the project into htdocs (XAMPP) or public_html (cPanel)
2. Create a MySQL database
3. Import database.sql
4. Update application/config/database.php
5. Open the project in browser

Default Login:
Create users manually in the database or via signup page.

Note:
This project is for educational and internal staff use only.
